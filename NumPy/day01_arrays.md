# NumPy Day 1: Arrays

## What is NumPy?

NumPy (Numerical Python) is a library used for fast numerical computations and array operations.

## Creating Arrays

```python
import numpy as np

arr = np.array([1, 2, 3, 4, 5])
print(arr)
```

Output:

```text
[1 2 3 4 5]
```

## Important Attributes

```python
print(arr.shape)
print(arr.ndim)
print(arr.dtype)
print(arr.size)
```
